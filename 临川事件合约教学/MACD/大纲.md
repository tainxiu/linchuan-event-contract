# MACD 合约教学大纲

## 1. MACD 是什么

- MACD 的三部分：DIF、DEA、柱状图。
- 默认参数：12、26、9。
- MACD 的本质是趋势动能指标，不是单独的买卖信号。

下面是 TradingView 的 MACD 指标源码（Pine Script v6），并对每个核心名词和参数做了详细解释：

```pinescript
//@version=6
indicator("Moving Average Convergence Divergence", "MACD", timeframe = "", timeframe_gaps = true)

// Inputs 输入参数
float  sourceInput  = input.source(close, "Source") // 源数据（通常为收盘价 close）
int    fastLenInput = input.int(12, "Fast length",   1) // 快线周期，默认12
int    slowLenInput = input.int(26, "Slow length",   1) // 慢线周期，默认26
int    sigLenInput  = input.int(9,  "Signal length", 1) // 信号线周期，默认9

// MA类型选择，EMA为指数移动平均（常用），SMA为简单移动平均
string oscTypeInput = input.string("EMA", "Oscillator MA type", ["EMA", "SMA"], display = display.none)
string sigTypeInput = input.string("EMA", "Signal MA type",     ["EMA", "SMA"], display = display.none)

// @function 计算 MA，按类型选用 EMA 或 SMA
ma(float source, int length, simple string maType) =>
    switch maType
        "EMA" => ta.ema(source, length) // 指数移动平均
        "SMA" => ta.sma(source, length) // 简单移动平均

// 计算 MACD 各数值（DIF, DEA, 柱状图）
float maFast = ma(sourceInput, fastLenInput, oscTypeInput) // 快线值
float maSlow = ma(sourceInput, slowLenInput, oscTypeInput) // 慢线值
float macd   = maFast - maSlow         // DIF，通常叫快线（快均线-慢均线）
float signal = ma(macd, sigLenInput, sigTypeInput) // DEA，又称信号线/慢线（DIF的均线）
float hist   = macd - signal           // 柱状图（MACD能量柱），代表动能变化

// 直方图颜色：上涨变强用绿色，下跌或变弱用红色
color hColor = hist >= 0 ? hist > hist[1] ? #26a69a : #b2dfdb : hist > hist[1] ? #ffcdd2 : #ff5252

hline(0, "Zero", #787b8680) // 画零轴
plot(hist, "Histogram", hColor, style = plot.style_columns) // 柱状图
plot(macd, "MACD")        // DIF（快线）
plot(signal, "Signal line", #ff6d00) // Signal（DEA/慢线）

// 报警条件: 柱状图由增转减 / 由减转增
alertcondition(hist[1] >= 0 and hist < 0, "Rising to falling", "MACD histogram switched from a rising to falling state")
alertcondition(hist[1] <= 0 and hist > 0, "Falling to rising", "MACD histogram switched from a falling to rising state")
```

**名词解释与详细实现思路讲解：**

---

### 1. 名词解释（参数与指标组成）

- **Source（源）**：是参与 MACD 计算的基础价格数据，通常为 `close`（收盘价），也可以设置为开盘价等其他指标。源码通过 `input.source(close, "Source")` 实现灵活选择。
- **Fast length（快线周期）**：快线（短期均线）的计算周期，通常为12。表示计算12期的均线，反应市场价格短期变化。由 `input.int(12, "Fast length", 1)` 设定，变量为 `fastLenInput`。
- **Slow length（慢线周期）**：慢线（长期均线）的计算周期，通常为26，反映更长周期的价格趋势。通过 `input.int(26, "Slow length", 1)` 实现，变量为 `slowLenInput`。
- **Signal length（信号线周期）**：对 DIF 进行再次平滑处理的周期，默认9。由 `input.int(9, "Signal length", 1)` 设定，变量为 `sigLenInput`。
- **EMA（指数移动平均）/SMA（简单移动平均）**：两种均线算法。源码用一个 `ma` 自定义函数，根据参数选择调用 `ta.ema` 或 `ta.sma`。
- **DIF（快线）**：即两条不同周期均线的差值，`DIF = maFast - maSlow`。衡量短/长期趋势差异。
- **DEA（信号线/慢线）**：对 DIF 再次平滑，DEA = DIF 的一定周期均线，源码为 `signal = ma(macd, sigLenInput, sigTypeInput)`。
- **Histogram（柱状图）**： `hist = DIF - DEA`，实时反映行情动能增强或削弱。
- **Zero Axis（零轴）**：MACD 三条线的中轴线。通过 `hline(0, ...)` 实现，可视化多空分界。
- **alertcondition（报警条件）**：指标显著状态切换时触发警告，通过逻辑判断 hist 的前后变化自动生成 TradingView 警报。
- **plot（绘图）**：把上面得到的所有数值（histogram、DIF、DEA）用不同的样式和颜色直观地画在图表上。

---

### 2. 代码实现的详细编程思路

**（A）参数输入与类型选择**

- 指标参数的灵活性是通过 `input` 系列函数实现，所有周期参数和价格源都可以由用户自定义，方便实际交易策略开发和实验：
  ```pinescript
  float  sourceInput  = input.source(close, "Source")
  int    fastLenInput = input.int(12, "Fast length",   1)
  int    slowLenInput = input.int(26, "Slow length",   1)
  int    sigLenInput  = input.int(9,  "Signal length", 1)
  string oscTypeInput = input.string("EMA", "Oscillator MA type", ["EMA", "SMA"], ...)
  string sigTypeInput = input.string("EMA", "Signal MA type", ...)
  ```
- 这样做既能适配经典参数，也允许高级用户自定义任意参数方案。

**（B）均线封装与复用（MA 函数的设计）**

- MACD 三条线的计算核心都是移动平均线。为提高代码复用性与扩展性，源码自定义 `ma()` 函数作为工厂，根据参数调用 EMA 或 SMA：
  ```pinescript
  ma(float source, int length, simple string maType) =>
      switch maType
          "EMA" => ta.ema(source, length)
          "SMA" => ta.sma(source, length)
  ```
- 这样扩展支持更多类型时，只需在 `ma` 函数中增加分支即可。

**（C）MACD 各部分逐步实现**

1. **计算快慢线：**
    ```pinescript
    float maFast = ma(sourceInput, fastLenInput, oscTypeInput)
    float maSlow = ma(sourceInput, slowLenInput, oscTypeInput)
    ```
2. **计算 DIF：**
    - 快线减去慢线，直接实现 `DIF = maFast - maSlow`
      ```pinescript
      float macd = maFast - maSlow
      ```
3. **计算 DEA（信号线）：**
    - 对 DIF 做信号周期均线（EMA/SMA），平滑波动
      ```pinescript
      float signal = ma(macd, sigLenInput, sigTypeInput)
      ```
4. **计算柱状图 Histogram：**
    - `hist = DIF - DEA`
      ```pinescript
      float hist = macd - signal
      ```
5. **柱状图颜色处理：**
    - 通过前一个 hist 与当前比较，判断动能增强/减弱，并用不同颜色区分趋势强度：
      ```pinescript
      color hColor = hist >= 0 ? hist > hist[1] ? #26a69a : #b2dfdb : hist > hist[1] ? #ffcdd2 : #ff5252
      ```
    - 上涨或放量时变成绿色系，下跌或缩量为红色，有助于一眼识别关键变化。

**（D）可视化与报警机制**

- 通过 `plot` 和 `hline` 把柱状图、快线、慢线及零轴全都画在 TradingView 指标区，非常直观。
  ```pinescript
  hline(0, "Zero", #787b8680)
  plot(hist, "Histogram", hColor, style = plot.style_columns)
  plot(macd, "MACD")
  plot(signal, "Signal line", #ff6d00)
  ```
- 利用 `alertcondition` 实现柱状图动能的关键转折报警（如金叉死叉拐点），极大方便盘中复盘和策略预警。
  ```pinescript
  alertcondition(hist[1] >= 0 and hist < 0, "Rising to falling", ...)
  alertcondition(hist[1] <= 0 and hist > 0, "Falling to rising", ...)
  ```

### 3. 逻辑梳理与编程实现步骤总结

1. **输入所有参数并选择均线类型** → 保证适配各种风格和场景。
2. **用自定义函数封装均线算法** → 代码复用且便于扩展。
3. **基于参数分步实现快线、慢线、DIF、DEA、柱状图** → 核心指标全部逐层计算且分明。
4. **根据柱状图的变化赋予不同颜色** → 可视化动能强弱。
5. **全部数值作图展示并加上报警条件** → 可视化和提醒功能直接融入代码核心。
6. **逻辑流程结构化、模块化** → 方便后续功能扩展，也易于教学和解读。

## 2. MACD 快速预测5-10分钟涨跌的参考用法

在事件合约、短线量化等场景下，MACD 可用来辅助预测接下来5-10分钟内的涨跌。以下为几个实用参考用法：

1. **DIF/DEA金叉死叉判定**  
   - 若 5min K 线的 DIF 从下向上穿越 DEA（金叉），通常预示后续5-10分钟上涨概率大增。  
   - 反之，DIF 向下穿破 DEA（死叉），短线下跌概率加大。

2. **MACD 柱状图动能变化**
   - 柱状图由负转正（hist < 0 → hist > 0），短线上涨；由正转负则短线下跌。
   - 若柱状图持续放大，趋势继续，多空信号更强。

3. **跨周期联动**
   - 结合1分钟、5分钟、15分钟周期的MACD信号，若多个周期同步“金叉”或同步“死叉”，则5-10分钟方向信号更可靠。

4. **背离用法**
   - 价格创新低，而MACD指标未创新低（底背离），预示反弹。  
   - 价格创新高而MACD未创新高（顶背离），预示短线回落。

5. **事件合约实践示例**
   - 设定 “5分钟内价格超前高/低” 的二元事件，根据MACD上述逻辑，在金叉/死叉等信号时下单，可提升胜率。

> ⚠️ 注意：MACD对极短周期也有滞后性，建议结合成交量等其他指标辅助判断，严格风控。
