# 临川事件合约教学第一期-新手基础

## 1. 如何分析比特币的价格走势

### 1.1 如何看趋势

- 学会画趋势线。

### 1.2 看盘口

常用工具：

- 币安现货盘口
- Coinglass 盘口
- Coinank 盘口
- Bookmap
- ATAS

### 1.3 确认 K

- 收针。
- 红绿红 / 绿红绿：后面的 K 要长于中间的 K。

![红绿红绿红绿确认K示例](图片/红绿红绿红绿确认K示例.png)

- 前提是有超过四根横盘，破新底 / 新高时出现有能量的 K，用来判断反转力量强不强。

![横盘破位能量K示例](图片/横盘破位能量K示例.png)

## 2. 反转形态

1. 有一根当前操作级别的反转 K 已经出现。
2. 在 0.618 的位置达成反转共识。

这个方法可以提前预判 MACD，通常会比 MACD 信号早 2-5 分钟。

![反转形态0.618共识示例](图片/反转形态0618共识示例.png)

## 3. 流动性：反转 / 顺势趋势参考点

### 3.1 参考工具

1. 爆仓指标：Coinglass。
2. 流动性热图：通常会呈现黄色的横盘区。

### 3.2 进场方式

- 左侧：遇到流动性时，参考大级别有没有反转的可能，可以直接左侧进场。

![流动性左侧进场示例](图片/流动性左侧进场示例.png)


- 右侧：出现同样的等长 K 两次，在第二次的时候进。

![流动性右侧等长K进场示例](图片/流动性右侧等长K进场示例.png)

## 4. MACD 如何运用在事件合约-此方法纯赌

1. MACD 在 0 轴下方 / 上方的时候，可以尝试左侧。
2. 在等同高点破掉之后买。
3. MACD 二次加强的时候买，震荡行情的胜算较高。
4. MACD 三次加强的时候补仓，不能吃的时候，通常代表极强单边。
